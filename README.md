# Proyecto-Final-Programacion-3
Sistema Distribuido de Coordinación y Gestión de Emergencias en Elixir
•	Fase 0: Configuración base (Proyecto, carpeta data/, Persistencia, Supervisor).
•	Fase 1: Usuarios y Login (Struct, GenServer, persistencia, LiveView, sesión).
•	Fase 2: Zonas afectadas (Estructura jerárquica recursiva Zona → Sector → Punto).
•	Fase 3: Recursos (Inventario, concurrencia clave, transferencias).
•	Fase 4: Necesidades (Prioridades, estados, asignación de recursos).
•	Fase 5: Albergues (Capacidad, ocupación, ingresos/egresos).
•	Fase 6: Personas y mensajes (Búsqueda, historial, comunicación familiar).
•	Fase 7: Mascotas (Reportes, algoritmo de coincidencias).
•	Fase 8: Dashboard global y resumen (summary).
•	Fase 9: Pruebas finales, diagramas y documentación.
